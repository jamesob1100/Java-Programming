# Java Programming

Java exercises and labs from my university coursework, covering core object-oriented 
programming concepts.

## Highlights

- **Library-App** — a library management console app demonstrating abstraction 
  (`LibraryItem` abstract class), interfaces (`Borrowable`), inheritance, and file 
  I/O with defensive parsing
- **Lab_AbstractClasses** — abstract class hierarchy (`LibraryItem`, `Book`, `Movie`) 
  with generated Javadoc documentation in `doc/`
- **Inheritance** / **Week4Inheritance2** — inheritance exercises (appliance and 
  person/student/staff class hierarchies)
- **Week13Lab** — polymorphism example with library member types (Student, Premium)
- **MyMathLibrary** / **MathLibraryDemo** — a small custom Java library with a demo consumer

## Tech stack
Java (Eclipse project structure)

## Note
Each folder is a standalone Eclipse project. Compiled output and IDE metadata are excluded via `.gitignore` — import any folder directly into Eclipse to run it.
